What it is

Markdown in, typeset PDF out, entirely in the browser. No backend, no telemetry, no accounts. A PWA that works offline once loaded.

A fork and rewrite of realdennis/md2pdf, kept only as far as the editor/preview split. Everything else — parser, theming, pagination, persistence, exports, chrome — was rebuilt. The PDF “engine” is paged.js plus window.print(); there is no PDF library anywhere in the tree.

Deletions completed in Phase 7

The slide-out settings panel, the horizontal tab strip and the 52px header are gone, not deprecated. Invariant tests assert that .wp-panel, .wp-tab*, .page-count and the old header classes render nowhere. Anything proposing to “restore” them is proposing a rebuild.

Why Shiki was declined

Worth carrying into any future highlighting discussion, because the obvious objection is the wrong one. Shiki has a CSS-variable theming mode already; it emits 11 token variables against highlight.js’s 40, so the only mode compatible with five themes plus custom palettes is a downgrade in colour granularity. The price would have been +364 kB gzipped and roughly a second of blocking grammar compilation. No abort criterion actually triggered — the criteria tested a premise the measurements falsified.

Traps that recur

Each of these cost real time at least once. They are the highest-value thing to read before planning work that touches the same ground.

Container hooks cannot read each other

nonaction invokes every container hook inside one component, above the context it populates. A container hook reading a sibling gets nothing. Dependencies are pushed in as arguments or composed into a single hook instead — which is why useDocuments lives inside useText rather than beside it.

hit in phases 3, 6a, 6b.1, 6c.1

Invariant tests pass on broken code

Four separate times, a test written to guard a behaviour passed against deliberately sabotaged production code — because the fixture lacked the failure mode, or the assertion read a value the CSS transition had not applied yet. Every new invariant gets sabotaged before it is trusted.

6.5c · 6d.1 · 6d.2 · 7.2

A flex item’s automatic minimum beats flex-basis

flex: 0 0 260px computed exactly as written while the sidebar rendered 394px wide, because min-width: auto resolves to min-content and a child’s intrinsic width won. Tests assert resulting geometry, never the declarations.

7.1 sidebar

getComputedStyle mid-transition returns the old value

Reading a colour immediately after changing a class returns the value being animated from. A three-state indicator test passed on a dot that never changed colour until the transition was disabled before reading.

7.2 autosave dot

paged.js margins are grid columns

Page margins live as CSS grid columns on .pagedjs_sheet and .pagedjs_pagebox. Setting margin properties does nothing, and forcing those elements to display: block for print silently drops every margin.

5 · 6.5a

Blob URLs taint a canvas; data URLs do not

Rasterising an in-page SVG through a blob URL throws “Tainted canvases may not be exported” in Chromium even though the SVG was generated in that very page. Encode with encodeURIComponent, not btoa, which throws above U+00FF.

6d.2 mermaid → PNG

Playwright helpers lie in two specific ways

getByText matches every ancestor whose text is exactly the string, so one wordmark can count as three. And addInitScript re-runs on reload, so a test that seeds state then reloads is asserting the seed, not the interaction.

7.1 · 7.2

Vitest include globs must name .jsx explicitly

A component test written as .test.js fails to parse JSX; renamed to .jsx it silently matched no glob and ran zero tests while the suite reported green.

7.0

Test discipline

Three suites, and one rule that produced most of the value.

SuiteCommandFilesTests
Unit (Vitest)pnpm test31939
E2E parallelpnpm test:e2e:parallel29358
E2E pagedpnpm test:e2e:paged558

Pagination is serial with a long timeout — seven concurrent paginations saturate one CPU. The two projects exist for that reason alone.

The rule

Tests observe invariants, not discriminators — and an invariant test is not trusted until the production code has been deliberately broken and the test has been watched to fail. Fixtures must actually contain the failure mode the invariant guards against.
